Generar explicaciones y ejemplos

Todo ocurre en tu Mac con Ollama. No se envía nada a internet y no cuesta dinero.

Un modelo pequeño se equivoca. Escribe con mucha seguridad aunque esté inventando, sobre todo con cifras, pares de apriete y normativa. Todo lo que genere queda marcado como sin revisar hasta que lo confirmes tú. Trátalo como un borrador, no como apuntes.

Cómo dejarlo listo

Se hace una vez y ya no hay que volver a tocarlo.

  1. Instala Ollama desde ollama.com/download y ábrelo.
  2. En el Terminal, descarga el modelo:
    ollama pull qwen3:4b
  3. Permite que esta página hable con Ollama (una sola vez):
    launchctl setenv OLLAMA_ORIGINS "*"
    y reinicia Ollama después (salir del icono de la barra y volver a abrirlo).
  4. Vuelve aquí y pulsa Comprobar conexión.

Con 8 GB de RAM cierra el resto de aplicaciones mientras genera. Si el Mac se atasca, prueba con un modelo más pequeño: ollama pull gemma3:4b o ollama pull llama3.2:3b.

Llevar el banco a la app

Descarga el paquete, descomprímelo y copia la carpeta data dentro de public/ del repositorio, sustituyendo la que haya. Luego haz commit y push: GitHub reconstruye y publica la app sola.

Formatos que entiende el analizador

No hace falta que el texto venga limpio: prueba a pegarlo tal cual y revisa el resultado.

PREGUNTA: (Identificador nº 2778104)
Para engranar ejes que se cruzan
el tipo de dentado debe ser:
Respuestas
Recto
Helicoidal*
No puede realizarse este engranaje
Todas las demás son correctas.

La línea Respuestas separa el enunciado de las opciones, y a partir de ahí cada línea es una opción aunque no lleve letra ni guion. El identificador se guarda y sirve para no repetir preguntas nunca.

Flujo de trabajo recomendado

  1. Elige módulo y tema arriba del todo. Se quedan fijos: no hay que tocarlos en cada pregunta.
  2. Pega una pregunta, ponle el asterisco a la correcta y pulsa Ctrl+Enter.
  3. Con el modo rápido activado se guarda sola y el cuadro queda vacío para la siguiente. Si falta la correcta o algo no cuadra, se para y te la muestra para que la revises.
  4. Bajo el cuadro quedan las últimas cinco guardadas por si quieres deshacer.
  5. Cuando tengas un buen montón, ve a Explicaciones IA y genera de golpe.
  6. Exportar → data.zip → copiar en public/ → commit y push.

Para borrar o corregir preguntas ya guardadas, usa la pestaña Banco: pulsa una fila para editarla, o marca varias con las casillas y bórralas de una vez.
